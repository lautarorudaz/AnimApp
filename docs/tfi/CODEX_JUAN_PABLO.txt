Arquitectura: React/Vite, Firebase Auth+Firestore/Web SDK, Firestore Rules para
operaciones permitidas, Cloud Functions callable acotadas para altas privilegiadas,
transiciones de rutinas y Arevalito con IA. No Express ni API REST general. Dos
sedes moreno y edison; admin/recepcionista/profesor/alumno y visitante público.
Una sola rutina activa por alumno; cada nueva rutina crea ID propio; historial
inmutable; profesor actual autorizado, profesor anterior sin acceso. `users`
canónico por uid; `alumnos` ficha, `rutinas` contenido; DTOS compartidos.
State y Protection Proxy deben existir en código de servidor, no solo en UI.
Arevalito solo utiliza información institucional pública y aprobada; jamás
usuarios o rutinas privadas. Conservar biblioteca, plantillas y UI existente.
